# Data directory

```
data/
├── raw/         <- put the CIC-IDS2017 CSV files here (not tracked by git)
├── processed/   <- intermediate artefacts written by the pipeline
├── demo/        <- demo_flows.csv, generated by scripts/make_demo_data.py
└── nids.db      <- SQLite store (created automatically on first run)
```

## Getting CIC-IDS2017 — the short version

```bat
python scripts\download_dataset.py            :: downloads + installs, then verifies
python scripts\download_dataset.py --links    :: print the URLs if you prefer a browser
python scripts\download_dataset.py --zip <path-to-downloaded.zip>
python scripts\download_dataset.py --verify   :: check what is installed
```

## Getting CIC-IDS2017 — by hand

The dataset is published by the Canadian Institute for Cybersecurity at the
University of New Brunswick:

* Landing page: <https://www.unb.ca/cic/datasets/ids-2017.html>
* Direct download index: <http://cicresearch.ca/CICDataset/CIC-IDS-2017/>

Download the **flow-level CSV files** (the `MachineLearningCSV` /
`MachineLearningCVE` archive, roughly 220 MB compressed).  You do *not* need the
raw PCAPs — they are ~50 GB and this project computes its own flow features
from live traffic instead.

Unzip the archive and copy the eight CSV files into `data/raw/`:

```
data/raw/
├── Monday-WorkingHours.pcap_ISCX.csv
├── Tuesday-WorkingHours.pcap_ISCX.csv
├── Wednesday-workingHours.pcap_ISCX.csv
├── Thursday-WorkingHours-Morning-WebAttacks.pcap_ISCX.csv
├── Thursday-WorkingHours-Afternoon-Infilteration.pcap_ISCX.csv
├── Friday-WorkingHours-Morning.pcap_ISCX.csv
├── Friday-WorkingHours-Afternoon-PortScan.pcap_ISCX.csv
└── Friday-WorkingHours-Afternoon-DDos.pcap_ISCX.csv
```

**Filenames do not matter.** The loader searches `data/raw/` recursively for any
`*.csv`, identifies the label column by content, and canonicalises the headers,
so sub-folders and renamed files work too. If you keep the dataset elsewhere,
point `paths.raw_data_dir` in `config/config.yaml` at that folder, or run:

```
python scripts/train_model.py --data-dir D:\datasets\CICIDS2017
```

## What the loader does with these files

1. **Pass 1** reads only the label column of each file and counts the classes.
2. **Pass 2** re-reads them in chunks and keeps a seeded random subset of every
   class, spread across the files in proportion to where that class occurs
   (so the BENIGN quota is not taken entirely from Monday's capture).
3. Headers are canonicalised, identifier and degenerate columns are dropped,
   `Infinity` becomes `NaN`, duplicates are removed, and classes with fewer than
   `dataset.min_samples_per_class` rows are merged into `Rare_Attack`.

Caps live in `config/config.yaml` under `dataset:` — the defaults
(`max_total_rows: 400000`, `max_rows_per_class: 60000`) keep training under
about ten minutes on a laptop. Raise them for the full 2.83 M rows if you have
the RAM and the time.

## Nothing here is generated by attacking anything

`data/demo/demo_flows.csv` is either a sample of the CIC-IDS2017 records above
(measurements captured in a lab in 2017) or synthetic flow records fabricated in
memory by `src/simulation/synthetic.py`. Replaying them touches no network.
